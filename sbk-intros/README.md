# SBK MEDIA TV – Programme Intros (Remotion)
1920x1080, 30fps, 10s, with original synthesized audio (royalty-free).
- `npm run render:wisdom` / `render:story` / `render:homeboys` -> `out/*.mp4`
- `npm run studio` to edit timings/copy live.
- Audio: `python3 -I tools/make_audio.py`; logo prep: `python3 -I tools/prep_assets.py`.
